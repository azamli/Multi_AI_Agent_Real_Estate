AI Real Estate Agent

This project is a simple AI-based real estate application that helps users find and analyze properties.

It takes inputs like city, budget, and property details, then searches different real estate websites and shows useful results.

What it does
Searches properties from multiple websites
Shows details like price, bedrooms, bathrooms, etc.
Gives basic market analysis
Suggests whether a property is a good investment
Tech Used
Python
Streamlit
Firecrawl
Groq
How to run
pip install -r requirements.txt
streamlit run app.py
Requirements
Groq API Key
Firecrawl API Key
About

I built this project to learn how AI can be used to automate property search and analysis.
